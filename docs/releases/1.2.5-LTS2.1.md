# Komari 1.2.5-LTS2.1

这是 1.2.5 LTS 分支的安全与稳定性维护版本，保留现有数据库结构和前后端兼容方案。

## 安全修复

- 账户密码改用 bcrypt cost 12。旧版 SHA-256 密码仍可正常登录，并会在登录成功后自动迁移，无需手动重置。
- 修复主题市场下载的 SSRF 与 DNS rebinding 风险。下载连接会校验并直连解析后的公网 IP，所有重定向均重新校验。
- 使用 Go 1.25 `os.Root` 限制备份恢复、主题与插件文件访问，修复路径穿越、符号链接逃逸和 Zip Slip 风险。
- 补全 OAuth、2FA 和临时访问 Cookie 的 Secure、HttpOnly 与 SameSite 策略。
- 修复无符号整数转换及指标序列容量计算可能发生的溢出。
- 将 `x/crypto`、`x/net` 与 `x/sys` 更新到当前安全基线，修复 Dependabot 报告的认证绕过、死锁、崩溃和拒绝服务问题。

## 稳定性修复

- 修正插件 `child_process.spawn` 的事件顺序，确保 stdout/stderr 完成读取后再触发 `close`，避免异步输出偶发丢失。
- 插件和主题静态文件通过已约束的文件句柄响应，避免路径校验与实际读取之间的竞态。
- 主题上传改用独立临时文件，避免并发上传互相覆盖。

## CI 与发布

- GitHub Actions 使用最小化 `GITHUB_TOKEN` 权限。
- `1.2.5-LTS` 每次提交都会生成以 UTC+8 日期时间命名的 Snapshot prerelease 和容器镜像。
- 正式容器镜像将发布 `1.2.5-LTS2.1` 与 `latest` 标签。

## 兼容性说明

- 数据库类型和数据库结构没有变化，可从 `1.2.5-LTS2` 直接升级。
- 内网或本机 HTTP 地址不再允许作为主题市场下载源；这是 SSRF 防护的一部分。
- 本版本继续使用 `1.2.5-LTS2-web` 前端。
