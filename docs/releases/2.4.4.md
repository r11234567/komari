## 2.4.3 → 2.4.4

- 完善节点注册、浏览器绑定登录和短时绑定票据，修复 Passkey 登录后的页面跳转。
- 加强 Agent 认证：引入设备审批、凭据续期、DPoP 请求校验与签名指令，移除旧 Agent JSON-RPC 和 Nezha 兼容入口，远程控制默认关闭。
- 重整特权配置下发：区分期望配置、机器实际状态和已应用快照，修复确认状态、失败回执、重复审批及恢复后状态同步；符合条件的新节点自动协商初始 r1 / 1。
- 增加本机 Host 操作进度、PAM 认证和事务恢复链路，完善 WebSSH、远程执行、GPU 与救援操作的权限及二次验证边界。系统密码不经过面板或 Agent。
- 更新面板特权配置界面、配置查询命令提示和前端依赖安全修复，同步协议及内嵌前端。
- 修复 SQLite 特权配置更新死锁、脚本子进程输出阻塞及 URL.origin 丢失端口等问题。

升级提示：Linux 特权身份切换仍需按面板提示在机器上执行 `sudo komari-host apply` 并完成本机 PAM 认证。安装器更新和依赖准备使用 Agent 仓库 main 分支的 `install.sh`；本次安装器修复不要求发布新的 Agent 二进制。
