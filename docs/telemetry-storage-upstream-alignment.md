# 遥测存储：普通标量 SQL 与原始 JSONL-zstd 分离

2026-11-14 修订。本文取代此前保留分位摘要、压缩统计扩展及一天原始 SQL 的设计。本文不是容量达标证明；实现与验收结果分开记录。

## 产品范围

SQL 只服务实例 CPU/GPU/内存/磁盘/负载图、Ping/丢包图和 `/admin/dashboard`；原始 `.jsonl.zst` 服务 CSV。业务流量账本继续保存实际整数 byte 与校准语义。

不在 SQL 写压缩块、压缩 BLOB、统计 JSON、t-digest、M2 或分位包。历史聚合支持 avg/min/max/sum/count/last；明确拒绝 first/stddev/P50/P95/P99，前端旧选择回退到 avg。缺失统计不填成零，不以均值冒充分位。

## 一份输入、独立交接

```text
上报 -> 热 SQL 原始队列事务 -> 确认接收
             |-> 普通标量桶 + 统计水位
             |-> 必要流量交接
             |-> 按机器/观测日写不可变 .jsonl.zst
                   三项交接完成 -> 退出交接队列
                       |-> 图表近窗原始行脱离归档段，到龄删除
                       |-> 其余原始 SQL 立即删除
```

热 SQL 的归档队列与实时显示窗口有不同生命周期。交接完成后复用原 hot 行、清空 segment_id，保持最近 15 分钟可刷新/重连/重启读取；traffic.up/down 仅供 CSV 的原始增量不进入显示窗口。两者合计受默认 16 MiB 接收预算约束，没有额外复制一张实时表。预算是估算字节，不能当成实际 SQLite 文件大小，磁盘还需计入索引、空闲页、WAL/SHM。

默认逻辑段目标 4 MiB、最长 24 小时，遇观测 UTC 日变化、点数/字节限额也封段。旧默认 15 分钟配置升级为 1440 分钟；接近队列预算时只封最大的一个开放分区，避免把所有机器的小尾巴同时封掉。telemetry_members 按批内序列汇总后各写一次，不逐点 UPSERT。

删除必须同时满足：文件发布与目录提交成功、统计水位覆盖、必要流量已交接、无有效读取租约。清理检查文件存在、普通文件属性和长度，不每批重新 SHA 和全文件解压。发布后的介质损坏由读取时 zstd checksum 检出，再由备份恢复。

不生成逐报告 payload SHA，也不为在线重试保存来源证明。pending 收据只存自然身份、消费顺序和交接状态；同一输入仍在队列时按身份去重，交接完成就删除。完成后再次重试允许少量重复观测，不扫描冷档核账，不把哈希账本转移到归档。业务流量仍通过独立整数账本交接。

## 主 SQL

- telemetry_rollup_keys 将既有序列身份映射到短整数。
- telemetry_rollup 主键为 (series_id,resolution,bucket)，分辨率和桶起点用秒。只保留八个值列：n、loss、total、minimum、maximum、last_value、first_offset、last_offset；尝试数=n+loss，观测边界为桶起点后的纳秒偏移。不存重复 attempts、完整时间戳、末次 ingest/ordinal、归档 owner 和 digest。
- telemetry_rollup_due 每序列/层只保存最早到期桶，不为全部历史再建完整工作索引。
- telemetry_raw_gaps 只记录迁移前原始数据已缺失的范围，按序列合并，不是逐桶证明链。
- telemetry_latest 每序列一行实际最后观测，按指标保留期回收，迟到输入不回退，擦除同步删除。离线 last 不依赖 15 分钟窗口；历史 LatestBefore 跨过不可拆桶时明确返回不可用，不把桶起点或当前快照冒充历史原值。

SQLite 使用普通 WITHOUT ROWID 表。图表不打开冷档。原始队列、收据、outbox、归档目录各有有限生命周期；旧 telemetry_summary 仅供升级读取，转换后清空。

net.total.up/down、traffic.up/down、process.count、connections.tcp/udp 不写资源历史图表桶。原始值仍归档用于 CSV；流量趋势与计费使用各自既有的分钟表和整数账本。前端历史选择器不再暴露这些资源图表不支持的序列，实时展示不受影响。

统计与消费水位同事务。均值=sum/n；父级直接相加人口与和。Ping 延迟分母是有效数，丢包分母是尝试数。零延迟有效，负时延是失败；全失败桶保留丢包人口，不伪造 0ms。

近窗查询的起止边界可能切过一个已汇总的 10 秒桶。只要完整原始人口仍在显示热表，就在同一读取快照内用这些原始点细化边界，不因为已经汇总而报缺口。细化先确认该时间范围没有其他分辨率的加性人口，再用既有 attempts 数确认原始人口没有删失；缺原始点或所有权不明确时仍返回 coverage 缺口。边界细化与未汇总尾部共用 10,000 行及图表内存预算，不读取冷档、不新增存储副本或核验哈希。

## 年龄降采样

| 观测年龄 | 分辨率 |
| --- | --- |
| 1 小时内 | 10 秒 |
| 1 天内 | 1 分钟 |
| 2 天内 | 5 分钟 |
| 7 天内 | 30 分钟 |
| 15 天内 | 1 小时 |
| 60 天内 | 2 小时 |
| 180 天内 | 6 小时 |
| 365 天内 | 12 小时 |
| 更老、指标尚未到期 | 1 天 |

输入按真实观测年龄直接写目标层，不预生成全部祖先。到期合并父桶与删除子桶同事务；迟到输入只增加对应标量，不能再计已有父桶。指标保留期沿用配置，不为缩容擅自缩短。

粗桶不能拆成不存在的细数据。边界或输出格子穿过不可拆分人口时返回明确 gap；不能只返回同桶细增量却声称总人口完整。原始 CSV 发现迁移前原始缺失时报错，不悄悄导出不完整数据。

查询步长同时考虑 start 的绝对年龄和查询内实际存在的源层，取兼容的整数倍；拖动到旧时间不能继续请求已不存在的细格。24 小时图使用 5 分钟/288 格，不能为凑 360 点产生不整除 5 分钟桶的 4 分钟格。

## 冷档与 CSV

新段按机器/观测 UTC 日分区。v3 是普通 point JSONL，按约 1 MiB 明文或机器变化切帧，不再每 128 点重开压缩器。每帧用 zstd checksum，无嵌套 SHA 和帧头/尾证明。

同机同 UTC 日共享一个只追加的物理文件，到 64 MiB 压缩大小后换文件。逻辑交接段是该文件中的 offset/length extent，每个 extent 保留原有有界帧索引及 CRC32；不增加一份全文件重复索引。追加仅复制新压缩字节，不解压重写已发布前缀；SQL 记录已提交末端，崩溃重试只截断未发布尾巴。文件同步保护交接，目录仅新建时同步，不对既有父目录反复全链同步。

先按授权机器/时间和 extent 选择，再解压所需帧。兼容旧 standalone/v2，旧混合文件仍可能需扫描；新格式单机 CSV 不解码其他机器。备份对共享物理文件去重并复制快照已提交前缀；冻结导出复制选中 extent，防止追加影响快照。同文件所有 owner 到期才删除物理文件。已有旧碎文件仍可读，本轮不批量解压重压历史档案。

新归档不生成整文件 SHA；SQL 的旧 checksum 兼容字段留空。读取依靠 zstd 自身校验检测损坏。历史带 SHA 的旧文件保留兼容读取，但不为新归档建立核对链。

CSV 清单每任务解析一次，缓存限制任务数；每步检查文件身份和 generation。输入字节前缀和一次建立。raw/sample30s 每批至多 32 单元、4 MiB 压缩输入或 2 秒，推进一次持久恢复点。sample30s spool 一批一个事务，宽 CSV 也按批提交，不每 128 行 fsync。恢复点先同步输出再提交游标；可重新生成的心跳/即时资源策略不做 fsync。没有全盘 sync。

## 迁移与回退

schema 10 开始转换先写 -10，防止旧二进制打开半转换库或误读共享归档文件。旧统计按 owner/series 组同事务读入、写标量、删除源；中断可继续。旧 receipts 的 payload_hash 及永久重试账本被删除。升级前中断的离线导入可暂用旧 opaque identity 恢复，完成后一起删除。无法安全识别的非嵌套重叠保留源并报错，不擅自合并人口。

离线导入完成必须封存、归档和清空最后短段的交接所有权/预算；完成 marker 不能留下永久交接尾部。近窗显示行仍按显示窗口到龄删除，不能为让整张 hot 表为空而破坏实时图。

离线导入使用固定导入时钟管理段生命周期，不能让历史观测窗口推进封段时钟。同一机器/观测日的稀疏窗口按字节/点数/热预算封段，不每个三小时窗口制造一个小文件。退休后的替换库清除进程 leases、work owner 等临时状态，避免将维护读取租约永久复制进去。

telemetry-migrate --confirm-offline 保留旧源表供回退，并不代表最终文件已缩小。完整退休用 telemetry-compact --confirm-offline --retire-legacy --output ... --backup-dir ... 生成验证后的新文件，再停机安装。此处备份/文件交换校验是一次维护边界，不是在线逐桶核账。

## 验收

大框架完成后统一验证，不每个小改动跑全套：

1. 标量人口、各年龄边界、迟到/重复、中断恢复、零延迟/丢包、删除屏障、损坏与权限隔离。
2. 旧源迁移、缺失声明、备份/恢复、退休后重开；图表和业务账本分别对照独立原始参考。
3. 实际构建的浏览器 E2E：实例资源/Ping 图和 /admin/dashboard，检查 HTTP 数据、曲线、错误状态及截图。
4. 容量分列主 SQL、WAL/SHM、空闲页、热积压、冷档和临时文件；退休后继续接收/归档/降采样/导出，报告运行峰值与稳定值，不以 VACUUM 后尺寸代替。

生产快照只在仓库外本地私有副本验证。数据库、原始导出、身份日志和截图禁止进入公开仓库或 CI；公开回归只用公式合成输入。
