# 流量账本

新版 Agent 每 30 秒采集所选网卡的累计发送和接收字节。未确认样本保存在凭据目录旁，每个队列最多 16 MiB，补传窗口接近 48 小时。面板把采样序号、计数器基线及待入账事件一同提交后回执，Agent 收到回执就删除相应明细。服务重启后的补传继续使用原序号。

在管理端节点列表打开「流量重置与校准」设置每月重置日、时分和时区。修改已有账期会在旧账期结束时生效，新账期从这个边界起算，至新规则的下一个重置点结束。页面显示生效时间。已有秒级重置点会沿用，直到显式修改。没有该日期的月份会在月末重置。

同一计数器的短采样间隔跨越账期时，面板按两边占用时间分配，两个账期的字节数相加等于原增量。超过两分钟的跨期增量会记入「待归属」。更换网卡或计数回退会建立新基线。能够确认宿主机已重启时，重启前的缺口与新启动后的增量分别记录。

校准时填写供应商用量和供应商统计截至的本地时刻。面板保留供应商值，并将截点后的增量加到该值上。截点前的迟到采样更新原始账本。比如截至 15:30 校准为 500 GB，之后计费增长 8 GB，页面显示 508 GB。校准只对本期生效，原始字节和历史校准保留。

先升级面板，再部署新版 Agent。旧 Agent 在升级前沿用原上报格式。新版 Agent 收到首个流量采样回执后停用旧的本机月度账本。管理端分别显示最后接收和入账时刻，可用来区分网络补传与后台入账延迟。
