# 流量监测

在节点的 **配置下发 → 特权配置** 中打开 **启用流量异常检测**，保存并确认。已以 root 运行的 Linux Agent 自动选择默认网卡、启动采集并上报。需要切换到 root 的节点使用现有本机授权流程。自动采集需要支持 TCX 的 Linux 内核。

打开后台 **流量监测**，选择节点查看采集状态和小时汇总。**异常事件**可展开查看该网卡观察到的入站来源 IP、出站目的 IP 和字节数。NAT、反代和隧道会改变观测地址。需要自定义网卡或服务归因时可使用 [Agent 手动模式](https://github.com/r11234567/komari-agent/blob/main/docs/traffic-anomaly-pilot.md#手动模式)。

小时汇总保留 7 天，异常快照从采集结束起保留 72 小时。重复上报不会刷新过期时间。流量归因用于解释用量，计费仍使用面板的流量账本。普通汇总没有对端地址和代理用户名。异常详情仅可通过管理员浏览器会话读取，查看操作进入操作日志。

数据写入独立的 `data/traffic-evidence/store.db`。面板生成的备份不会打包该文件。如果宿主机有整目录备份，需要排除 `data/traffic-evidence/`，以便过期快照随面板留存策略清理。
