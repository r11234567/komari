# 流量取证

在管理后台打开 **流量取证**，选择已绑定的 Linux 节点。**小时汇总**展示公网网卡的统计以及 Xray、系统更新、备份和其他代理的归因。**异常事件**可展开查看所选网卡上观察到的入站来源 IP、出站目的 IP 和字节数。NAT、反代和隧道会改变该位置能看到的地址。

先在计费节点安装兼容的采集工具并完成本地授权。启用面板上报需要配置 Agent 服务的专用中转目录。见 [Agent 流量取证部署说明](https://github.com/r11234567/komari-agent/blob/main/docs/traffic-anomaly-pilot.md#在面板查看)。

小时汇总保留 7 天，异常快照从采集结束起保留 72 小时。重复上报不会刷新过期时间。流量归因用于解释用量，计费仍使用面板的流量账本。普通汇总没有对端地址和代理用户名。异常详情仅可通过管理员浏览器会话读取，查看操作进入操作日志。

数据写入独立的 `data/traffic-evidence/store.db`。面板生成的备份不会打包该文件。如果宿主机有整目录备份，需要排除 `data/traffic-evidence/`，以便过期快照随面板留存策略清理。
